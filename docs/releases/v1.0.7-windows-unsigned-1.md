# SoundControl v1.0.7 — Windows installer (UNSIGNED test build)

**Windows installer:** `SoundControl-Setup.exe` — for **Windows 11 / Windows desktop testing**.
Application version **1.0.7** (this release does not change the application version; it makes an
already-built, already-tested CI installer publicly downloadable).

> ## ⚠️ This installer is UNSIGNED
>
> `SoundControl-Setup.exe` in this release has **no Authenticode signature**. It is **not signed**
> and **not production-certified**. Because Windows cannot verify a publisher identity for an
> unsigned file, **Windows may display a SmartScreen / "unknown publisher" security warning**
> when you download or run it. That warning is expected for an unsigned build and is not a virus
> detection. Verify the SHA-256 checksum below before running the installer.

## What this build is

- An NSIS installer with Start-menu and desktop shortcuts and a bundled Python Bluetooth runtime —
  no Node.js or Python installation is needed on the user's machine.
- Devices must already be paired and connected in the host's Windows Bluetooth settings before the
  app can talk to them.

## What this build is not

- **Not signed** and **not an official/production Windows release**. Official Windows releases
  remain gated on Authenticode signing: the **Release Windows** workflow refuses to build without
  a valid code-signing certificate and verifies the real generated installer's signature before it
  publishes anything. This pre-release exists precisely because it is *not* that.
- **Not physical Soundcore hardware validation.** CI build/install/smoke checks are automated
  validation only. The hardware validation record
  ([HARDWARE-VALIDATION.md](https://github.com/Shankers8811/soundcontrol/blob/main/HARDWARE-VALIDATION.md))
  is unchanged by this release and still records what has and has not been tested on physical
  devices.
