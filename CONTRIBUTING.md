# Contributing

Thank you. SoundControl is unofficial. Be kind, and do not claim it is an Anker product.

## Issues

Use the templates:

- **Device does not connect** — browser, OS, model, firmware if you know it
- **Feature request** — what the official app does that we do not

Search existing issues first.

## Pull requests

1. Keep the UI close to the soundcore Android companion **without Anka**
2. New opcodes belong in `src/protocol/` with a comment and a hex example
3. Do not add analytics, accounts, or AI chat

## Safety

Do not publish exploit payloads. Firmware writes you have not captured yourself should stay behind a comment, not a default button.
